# @formxjs/vue-ep

## 中文

`@formxjs/vue-ep` 是 FormX 的 Vue + Element Plus 皮肤包。它把 `@formxjs/ui-core` 产出的 `FieldView`、`ContainerView` 和字段组命令渲染成 Element Plus 表单组件。

```ts
import { FormX } from '@formxjs/vue-ep'
import '@formxjs/vue-ep/style.css'
```

适合已经使用 Vue 3 和 Element Plus 的后台、配置平台、低代码设计器和复杂业务表单。

## English

`@formxjs/vue-ep` is the Vue + Element Plus skin for FormX. It renders `FieldView`, `ContainerView`, and field-group commands from `@formxjs/ui-core` as Element Plus form components.

```ts
import { FormX } from '@formxjs/vue-ep'
import '@formxjs/vue-ep/style.css'
```

It is suitable for Vue 3 + Element Plus admin systems, configuration platforms, low-code designers, and complex business forms.

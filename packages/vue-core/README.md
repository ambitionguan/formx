# @formx/vue-core

## 中文

`@formx/vue-core` 是 FormX 的 Vue 运行时桥接包。它负责把 headless engine 和 UI view runtime 接入 Vue 的响应式系统，提供 engine 生命周期、视图快照订阅、字段组状态、折叠状态和组件暴露 API 等能力。

它不绑定 Element Plus。任何 Vue 皮肤都可以基于这个包实现，例如 Element Plus、Ant Design Vue 或完全自定义组件库。

## English

`@formx/vue-core` is the Vue runtime bridge for FormX. It connects the headless engine and UI view runtime to Vue reactivity, providing engine lifecycle handling, reactive view snapshots, field-group state, collapse state, and exposed component APIs.

It is not tied to Element Plus. Any Vue skin can build on this package, including Element Plus, Ant Design Vue, or custom component libraries.

# Security Policy

## Supported Versions

FormX is pre-1.0. Security fixes will target the latest published minor version.

## Reporting a Vulnerability

Please do not open a public issue for suspected vulnerabilities. Use GitHub private vulnerability reporting if it is enabled for the repository, or contact the maintainers through the repository owner.

Include:

- Affected package and version.
- Reproduction steps or proof of concept.
- Impact and any known workaround.

We will acknowledge valid reports as soon as possible and coordinate a fix before public disclosure.

# Business Scenarios

The full workbench is available at:

```bash
pnpm --filter @formx/example-vue-ep-basic dev
```

It includes:

- Full capability showcase.
- Connection configuration.
- Controls matrix.
- Data protection policy.
- Remote options policy.
- Runtime `setOptions`.
- Deep order linkage.
- User onboarding linkage.
- Permission matrix.

These examples demonstrate how FormX handles nested value trees, array scopes, remote resources, cross-field rules, async hydration, and submit validation.

# Examples

FormX examples are live documentation: the forms on these pages are real FormX components, not screenshots.

| Example | What it covers |
| --- | --- |
| [Basic Form](/en/examples/basic) | Rendering, `v-model:value`, built-in controls, submit validation. |
| [Linkage](/en/examples/linkage) | `showWhen`, `requiredWhen`, `rulesV2`, value effects. |
| [Remote Options](/en/examples/remote-options) | `optionsFrom`, `ResourceManager`, params, runtime fetch. |
| [Field Group](/en/examples/field-group) | Array fields, add/copy/remove operations, scoped rules. |
| [Validation](/en/examples/validation) | Required rules, named patterns, async validators. |
| [Headless Core](/en/examples/headless-core) | `FormXEngine` without Vue renderer. |
| [Scenario Patterns](/en/examples/business-scenarios) | General patterns for complex application forms. |

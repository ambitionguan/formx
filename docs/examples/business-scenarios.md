# 业务场景

除了文档页里的基础 demo，FormX 仓库还提供一个完整示例工程：

```bash
pnpm --filter @formx/example-vue-ep-basic dev
```

示例位置：

```txt
examples/vue-ep-basic
```

## 场景列表

| 场景 | 重点能力 |
| --- | --- |
| 全量能力展示 | 字段、容器、数组、远程选项、上传、自定义组件、运行时 patch。 |
| 连接配置 | 接近生产配置弹窗，多字段组和自定义操作。 |
| 控件矩阵 | switch、slider、cascader、time、upload、远程 options。 |
| 数据保护策略 | 字段组、保护方法和作用范围联动。 |
| 远程选项策略 | `optionsFrom` 与规则联动组合。 |
| 运行时 setOptions | 使用 `rulesV2` 动态改写字段选项。 |
| 订单深层联动 | 对象、数组、跨层字段和审批条件。 |
| 用户入职联动 | 多区块流程和深层对象。 |
| 权限矩阵 | 矩阵型字段组、动态必填和提交校验。 |

## 为什么这些示例重要

简单动态表单只需要渲染字段。复杂业务表单需要处理：

- 多层值树。
- 数组项作用域。
- 远程资源和参数依赖。
- 跨字段、跨数组联动。
- 异步回填和提交校验。
- UI 皮肤与核心逻辑解耦。

这些场景能帮助使用者判断 FormX 是否适合自己的项目，而不是只看到几个控件截图。

## 建议阅读顺序

1. 先看控件矩阵，了解当前 Vue + Element Plus 皮肤支持什么。
2. 再看数据保护策略，理解 `field-group` 和业务联动。
3. 再看连接配置，理解复杂弹窗如何组织。
4. 最后看权限矩阵和深层联动，理解作用域和规则图。
